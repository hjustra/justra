Justra PJe Capture

Política de Privacidade

Esta política explica quais dados a extensão trata, para que eles são usados e quais dados ela não coleta.

Última atualização: 2 de julho de 2026.

A Justra PJe Capture tem um único propósito: capturar conteúdo visível ou acessível na página de processo do PJe aberta pelo usuário e importar esse conteúdo para a plataforma Justra.

1. Escopo desta política

Esta política se aplica à extensão Justra PJe Capture para navegador Chrome e ao fluxo de importação de dados do PJe para a Justra.

A extensão funciona somente quando o usuário está em uma página de processo do PJe coberta pela extensão e aciona voluntariamente uma ação de captura, download ou envio para a Justra.

2. Dados que a extensão pode tratar

A extensão não coleta dados comportamentais do usuário. Ela trata conteúdo da página de processo do PJe aberta pelo próprio usuário. Esse conteúdo pertence aos autos ou à página processual, mas pode conter dados pessoais ou sensíveis de partes, advogados, testemunhas, peritos e outros envolvidos.

Dependendo do conteúdo disponível no processo, a extensão pode capturar e importar:

  • Dados de identificação processual, como número do processo, tribunal, órgão julgador, classe processual, datas e movimentações.
  • Conteúdo visível do site do PJe, incluindo textos, títulos, links, documentos listados, referências documentais e metadados exibidos na página.
  • Dados pessoais presentes nos autos, como nomes, números de documentos, endereços, dados profissionais, dados de partes, advogados ou terceiros.
  • Dados financeiros presentes nos autos, como valores de causa, salários, verbas trabalhistas, cálculos, depósitos, acordos, comprovantes ou informações similares.
  • Comunicações pessoais presentes em documentos processuais, como e-mails, mensagens, conversas ou transcrições, quando tais conteúdos estiverem nos documentos capturados.
  • Informações de saúde ou outros dados sensíveis quando estiverem presentes nos documentos do processo, como atestados, laudos, perícias, CAT, sintomas, diagnósticos ou procedimentos.

3. Dados que a extensão não coleta

A Justra PJe Capture não coleta, registra nem transmite:

  • Senhas, PINs, perguntas de segurança, certificados digitais, tokens de autenticação ou credenciais do PJe.
  • Cookies de autenticação do PJe ou credenciais de login.
  • Histórico geral de navegação do usuário.
  • Localização do dispositivo, coordenadas de GPS ou dados de proximidade.
  • Cliques, posição do mouse, rolagem, teclas digitadas ou dados de monitoramento comportamental.
  • Dados para publicidade, perfilamento, venda de dados, análise de crédito, empréstimos ou determinação de credibilidade.

4. Como os dados são usados

Os dados capturados são usados exclusivamente para importar para a Justra o conteúdo visível ou acessível do processo aberto pelo usuário no PJe.

Na Justra, esse conteúdo pode ser usado pelo próprio usuário para consultar, organizar, pesquisar e trabalhar com o material processual importado. A extensão não usa os dados para finalidades independentes do seu propósito único.

5. Compartilhamento e transferência

A extensão transmite o conteúdo capturado para a Justra somente quando o usuário aciona a importação. A Justra não vende dados de usuários e não transfere dados para terceiros fora das hipóteses necessárias para fornecer, manter, proteger ou cumprir obrigações legais relacionadas ao serviço.

Os dados não são usados ou transferidos para publicidade personalizada, retargeting, pesquisa de mercado, análise de crédito, empréstimos ou determinação de credibilidade.

6. Armazenamento local

A extensão pode usar armazenamento local do navegador para manter configurações, preferências, estado da captura ou dados temporários necessários ao funcionamento da importação.

Esse armazenamento é limitado ao necessário para a funcionalidade da extensão e não é usado para rastreamento ou publicidade.

7. Segurança

A extensão não baixa nem executa código remoto. O código JavaScript necessário ao funcionamento da extensão é empacotado junto com a própria extensão.

As transmissões de dados para serviços da Justra devem ocorrer por conexão segura em ambiente de produção. Fluxos locais de desenvolvimento podem usar endereço local do próprio computador, como 127.0.0.1, apenas para testes autorizados.

8. Retenção

Os dados importados permanecem na plataforma Justra conforme a conta, configuração, contrato ou solicitação do usuário. Dados temporários mantidos pela extensão no navegador podem ser apagados pelo usuário ao limpar os dados da extensão ou remover a extensão do Chrome.

9. Direitos e solicitações

O usuário pode solicitar informações sobre dados importados, correção, exclusão ou outros pedidos relacionados à privacidade pelo canal de contato da Justra.

Contato: contato@justra.app.

10. Alterações nesta política

A Justra pode atualizar esta política para refletir mudanças na extensão, na plataforma ou em exigências legais e regulatórias. A data de atualização será indicada no início desta página.
